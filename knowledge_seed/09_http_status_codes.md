# HTTP 状态码测试规则

## 客户端错误
400 表示请求整体不可处理；401 表示缺少或无效认证凭证；403 表示身份已知但无权限；404 表示资源不可见或不存在；409 表示当前资源状态冲突；422 表示语法可解析但内容不满足语义或校验约束。

## 服务端错误
500 表示服务内部未处理错误，502/503/504 常与上游或可用性相关。测试不应只断言状态码，还要检查错误体是否稳定、是否泄露内部信息，以及失败操作是否保持原子性。
